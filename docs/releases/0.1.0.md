The first release of Bellhop.

- **A tidy menu bar.** Bellhop tucks your menu bar icons behind macOS's overflow, so the bar stays clear on a small screen.
- **Keepers.** Bring back the few icons you use most, in the order you choose, by dragging them in the Bellhop panel.
- **Every icon in one list.** Rest on Bellhop's icon to see them all; rest on one to open its menu right there.
- **Search the menu bar.** Press ⌃⌥Space and type to run any menu item of any menu bar app, without the mouse.
- **`bellhop` on the command line.** List, search and run menu bar items from Terminal or scripts.

Bellhop needs Accessibility access to read and press menu bar items. It never records your screen, and nothing you
search or run leaves your Mac.
