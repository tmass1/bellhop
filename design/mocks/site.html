Find

Run any menu item without the mouse.

Press ⌃⌥Space and type a few letters. Bellhop searches every icon and every item in their menus, puts what you use most first, and asks twice before anything like Quit or Sign Out.

Command line

Scripts can use it too.

The bellhop command lists, searches and presses menu bar items, with JSON for scripts and agents. It talks to the app, so it never needs a permission of its own.

$ bellhop search "snooze hour"
Dropbox › Snooze Notifications › For the next hour

$ bellhop run "Dropbox › Snooze Notifications › For the next hour"
Pressed Dropbox › Snooze Notifications › For the next hour

$ bellhop keep Mark
In the menu bar: Burn, Mark

Privacy

It reads menus. That's all.

Accessibility, nothing else Bellhop reads and presses menu items the way VoiceOver does. It never records your screen.
Stays on your Mac What you search and run is kept in your user folder. No accounts, no analytics.
One request a day The only thing it fetches is the list of updates from GitHub. Each update is signed and checked before it installs.
